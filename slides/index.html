Workflow 1 · Live

Larry, the Lead Researcher

Webhook  →  Larry  →  Create Doc  →  Update Doc
            (Web-Search aktiviert,      → Google Drive
             routet Hot/Cold selbst)

Ein einziger Agent recherchiert jeden Lead und entscheidet im Prompt selbst zwischen Sales-Briefing (Hot) und Re-Engagement-Briefing (No-Show). Output: Google Doc im geteilten Ordner. Vier Nodes, kein Condition-Router — der Hebel ist das Prompt-Engineering.
